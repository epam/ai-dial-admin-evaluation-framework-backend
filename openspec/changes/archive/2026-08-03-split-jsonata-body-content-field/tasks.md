Groups are ordered by dependency: runner-core carrier + evaluator first (nothing compiles until the DTO settles), then the EF backend write path, then tests, then contract/docs. Per AGENTS.md a task is complete only when its tests have been **executed** and pass — a compile-clean build is not sufficient.
